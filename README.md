# superstore-sales-performance-dashboard
Excel sales performance dashboard using the Superstore dataset.

**Project Overview:**
- This project analyzes the Superstore sales dataset retrieved from Kaggle to identify sales, performance, profitability, product performance, and regional trends.
- This project also includes data cleaning, calculated fields, pivot table analysis, KPI development, and a first-time dashboard designed to present business insights clearly.

**Tools & skills:**
- Microsoft Excel
- Data Cleaning
- Data Validation
- Pivot Table
- Data Visualisation
- KPI Development
- Business Analysis
- Sales & Profit Analysis

**Dataset:**
This dataset contains around 9994 transaction records and 21 columns, including:
- Order ID
- Order Date
- Ship Date
- Customer
- Segment
- Region
- Category
- Sub-category
- Product
- Sales
- Quantity
- Discount
- Profit

**Data Preparation:**
The dataset was initially reviewed and prepared before analysis. Key checks included:
- Duplicated record checks using Row ID
- Missing value checks
- Date validation
- Creation of calculated fields

**Calculated fields:**
1. Shipping Days
=Ship Date-Order Date
2. Profit Margin
=Profit/ Sales
3. Revenue per Unit
=Sales/ Quantity

**Analysis**
These analysis were created using Pivot Tables:
- Sales by Region
- Sales & Profit by Category
- Monthly/ Yearly Sales Trend
- Top 10 Products
- Profit by Region

**Key Insights:**
1. **West** recorded the highest regional sales and profit.
2. **Technology** generated the highest sales and profit among the three major categories.
3. **Furniture** generated substantial sales but comparatively lower profit, indicating a weaker profit margin.
4. Sales increased substantially from **2014 to 2017**.
5. The dashboard highlights the **Top 10 products by sales** to identify high performing products.

**Project Objective:**
This project was my first hands on experience developing an end-to-end sales analysis dashboard in Microsoft Excel. The objective was to strengthen my practical skills in data cleaning, Pivot Table analysis, KPI development, and data visualization while transforming raw transaction data into meaningful business insights.
